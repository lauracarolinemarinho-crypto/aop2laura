# Arquivo de Runeterra — Legends Hub

Blog acadêmico sobre League of Legends, sua história, o mundo de Runeterra e o campeão Teemo.

## Páginas
- `index.html` — Home
- `historia.html` — História de League of Legends
- `teemo.html` — Teemo, o Explorador Veloz
- `runeterra.html` — Regiões e universo ficcional
- `jogo.html` — Como funciona o jogo
- `contatos.html` — Contatos

## Como visualizar
Abra `index.html` no navegador. As imagens são carregadas do CDN oficial do Data Dragon da Riot Games e as fontes são carregadas do Google Fonts; portanto, é necessária conexão com a internet para esses recursos.

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público no GitHub chamado `arquivo-de-runeterra`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço ficará no formato `https://SEU-USUARIO.github.io/arquivo-de-runeterra/`.

## Observação
O projeto é um trabalho independente de fã/estudante e não é afiliado à Riot Games. League of Legends, seus personagens e marcas pertencem aos respectivos titulares.
